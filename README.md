# Laura Miller | Miller Lab

Personal and lab website for Laura Miller, Professor of Mathematics at the University of Arizona.

Plain HTML and CSS, no build step needed to host it. GitHub Pages serves this folder as is.

- `index.html` home, `research.html`, `people.html`, `publications.html`, `teaching.html`
- `style.css` colors and layout (sky blue accent; add `data-accent="pink"` to the `<html>` tag for pink)
- `img/` photos and screenshots, `cv/` the public CV

The pages are generated from source kept on Laura's H: drive (`12-Personal-Website/source/build.py`); edit there and rebuild, or edit the HTML here directly for small fixes.
